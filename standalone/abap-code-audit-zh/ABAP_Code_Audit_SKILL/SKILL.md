# ABAP代码审计工具(中文) (ABAP Code Audit Tool - Chinese)

## 概述

专业的ABAP代码审计工具，帮助SAP开发者进行全面的代码质量评估、性能分析和安全检测。支持多种输入源，自动识别代码来源，**支持ABAP版本选择**，生成多格式审计报告。

---

## 核心功能

### 0. ABAP版本选择 ⭐ (交互A)

审计开始时**自动弹出交互界面**，让用户选择目标ABAP版本：

> **📁 报告输出目录**
> 所有审计报告默认输出到：`D:\My Documents\WorkBuddy_Workspace\Outbox\ABAP_Audit_Reports`
> 用户也可在审计时自行指定其他目录。

#### 交互界面

```
============================================================
📋 ABAP版本选择
============================================================

请选择审计适用的ABAP版本：

  1. 使用最新版本（推荐）

  2. 从列表中选择指定版本

请输入选项 [1/2] (默认1): 
```

| 选项 | 说明 |
|------|------|
| **1. 使用最新版本** | 自动选择 `version.json` 中标记的最新版本（推荐） |
| **2. 从列表中选择** | 实时从 `version.json` 读取，按版本由新到旧列出 |

### 1. 多输入源支持

| 输入类型 | 支持格式 | 说明 |
|----------|----------|------|
| 文本文件 | `.txt` | 单个TXT文件 |
| Markdown | `.md` | 自动提取代码块 |
| 压缩包 | `.zip` / `.rar` | 解压后批量处理 |
| **目录** | **文件夹** | **✅ 允许处理目录** |
| 代码片段 | 直接粘贴 | 用户输入的代码 |

### 2. ABAP来源识别

自动识别代码来源于SAP开发对象类型：

| 来源类型 | 说明 | 置信度标识 |
|----------|------|-----------|
| `REPORT` | 可执行程序或模块池 | 🟢 高 |
| `FUNCTION` | 函数模块 | 🟢 高 |
| `CLASS_DEF` | 类定义 | 🟢 高 |
| `CLASS_IMP` | 类实现 | 🟢 高 |
| `MODULE` | Module Pool或屏幕PAI/PBO | 🟡 中 |
| `FORM` | 子程序/FORM例程 | 🟢 高 |
| `FUNCTION_POOL` | 函数组 | 🟡 中 |
| `INTERFACE` | 接口定义 | 🟢 高 |
| `UNKNOWN` | 未知来源 | 🔴 低 |

## 配置说明

### 词元配置 (token.json)

位于 SKILL 根目录的 `token.json` 文件，用于自定义审计报告的用词风格。

**可配置的词元类型：**

| 分类 | 可调整内容示例 |
|------|----------------|
| **report** | 报告标题、前缀符号、分隔符、作者信息 |
| **sections** | 各章节标题（审计汇总、问题详情等） |
| **labels** | 字段标签（目标版本、文件名称、代码行数等） |
| **severity** | 严重程度标签和emoji（🔴严重/🟠高/🟡中/🟢低） |
| **issue_fields** | 问题详情字段（行号、规则、类别、建议等） |
| **messages** | 提示信息（发现X个问题、未发现问题等） |
| **category_names** | 类别名称（性能、安全等） |
| **format_selection** | 格式选择提示 |

**示例：修改严重程度标签**

```json
{
  "severity": {
    "critical": { "label": "致命错误", "emoji": "💀" }
  }
}
```

## 代码度量

审计报告会包含以下度量指标：

| 指标 | 说明 |
|------|------|
| 代码行数 | 有效代码行（不含注释） |
| 注释行数 | 注释行数 |
| 注释比例 | 注释占总行数比例 |
| 圈复杂度 | 代码复杂度评分 |
| 严重问题数 | Critical级别问题 |
| 高风险问题数 | High级别问题 |

## 使用限制

1. ~~**目录禁止**~~ → **目录允许**：支持处理文件夹
2. **文件大小**：单文件建议不超过1MB
3. **编码**：仅支持UTF-8编码
4. **PDF生成**：需要安装weasyprint或reportlab
5. **ABAP版本**：默认为最新版本，可手动指定
6. **默认输出格式**：HTML

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 文件不存在 | 提示用户检查路径 |
| 不支持的文件类型 | 提示支持的格式 |
| 编码错误 | 自动使用ignore跳过 |
| ZIP无效 | 提示重新压缩 |

## 与SAP Integration Suite集成

本工具可与 `SAP Integration Suite` skill 配合使用：

- 使用 **SAP Integration Suite** 识别ABAP代码来源类型
- 使用 **ABAP审计工具** 进行代码审计

### 集成调用示例

```
1. 先调用 sap-integration skill 识别代码来源
2. 根据来源类型应用不同的审计规则
3. 生成综合审计报告
```
